# Ride.Edu

Локальный React-прототип конструктора образовательных программ. Все данные и действия ИИ демонстрационные, внешних API нет.

```sh
npm install
npm run dev
```

Открыть адрес из вывода Vite. Сборка: `npm run build`.

На карте выберите модуль для редактирования. Стрелка в карточке раскрывает темы. Панель слева позволяет добавить модуль или выполнить одну из трёх моковых команд помощника.

После изменения структуры её нужно утвердить заново; сумма часов должна совпадать с заданным объёмом. Изменение содержания сбрасывает материалы затронутого модуля. Экспорт JSON скачивает реальные текущие данные; DOCX и PPTX — только текстовые превью. Новая программа использует демонстрационную базу по анализу данных при любом запросе. Автопроверка источников и нормативных шаблонов не реализована.

Состояние хранится в localStorage. Кнопка сброса в нижней части навигации восстанавливает исходный пример на 72 часа. Интерфейс рассчитан на ноутбук (от 1080 px). Автотесты не добавлены.
